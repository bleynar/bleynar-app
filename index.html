Как установить

  1. 1Скачайте APK и откройте файл в загрузках браузера.
  2. 2Если Android попросит разрешение, разрешите установку для этого браузера и вернитесь к файлу.
  3. 3Нажмите «Установить». Если Bleynar уже есть на устройстве, выберите «Обновить», чтобы сохранить свои настройки.
  4. 4С версии 1.7.1 по кнопке «Обновить» браузер скачивает новый APK с этого сайта. Откройте файл и подтвердите обновление в окне Android. После установки скачанные APK можно удалить из папки «Загрузки», чтобы освободить место.

При первом запуске разрешите уведомления одним нажатием. Bleynar подключит быструю доставку через сервисы Google, если они есть на телефоне, и запустит проверку канала в фоне. Изменить выбор можно через колокольчик.
