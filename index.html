С 22 ноября 2026 года учитываем первое полное скачивание через эту кнопку в каждом браузере. После очистки данных сайта тот же браузер может прибавить ещё одно скачивание. Прямые загрузки с GitHub и обновления из приложения сюда не входят.

Как установить

  1. 1Скачайте APK и откройте файл в загрузках браузера.
  2. 2Если Android попросит разрешение, разрешите установку для этого браузера и вернитесь к файлу.
  3. 3Нажмите «Установить». Если Bleynar уже есть на устройстве, выберите «Обновить», чтобы сохранить свои настройки.

При первом запуске можно включить уведомления о новых видео, Shorts и записях. Позже выбор можно изменить через колокольчик.
